## Critical Anti-Patterns (do NOT repeat these)

- **Custom timeouts wrapping Sparkle** — Sparkle's `SPUStandardUpdaterController` already drives all update states through delegate callbacks. Adding a parallel timer surfaces false errors that contradict Sparkle's own UI. → Trust the delegate methods; if you need user-visible state, derive it from `didFindValidUpdate` / `updaterDidNotFindUpdate` / `didAbortWithError`.
- **Releasing without a Developer ID Application cert** — ad-hoc signing + manual `codesign --force --deep -s -` re-sign of Sparkle.framework was a brittle hack causing `exit code 134` crashes. → Use `scripts/release.sh` exclusively; it handles signing + notarization + EdDSA + appcast in one shot.
- **Pinning CI to an Xcode version older than `Package.swift`'s `swift-tools-version`** — Caused months of red builds. → If `Package.swift` declares 6.2, CI must run on a runner that provides it, or the build job must be removed until it does.
